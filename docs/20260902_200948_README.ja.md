# 都道府県別・国籍別の犯罪統計と在留人口の収集・可視化

信頼できる情報源を検証し、全国・都道府県別・地域別の国籍別在留人口と犯罪統計を定期収集・更新して、件数と公表統計から再現可能に導いた参考比率をGitHub上で可視化する。

English: [README.md](./README.md)

## 背景 (Background)
在留人口と犯罪統計の公開情報は公表主体が分かれ、地理・期間・国籍区分が一致しない可能性がある。国籍labelだけが公正な定量contextなしに流通し、集団の本質や個人riskを示すかのような印象操作になることを避けるため、取得できる数字を正確に集め、比較不能な範囲も見える形にし、事実ベースの対策につなげる。詳しい問題設定と注意点は [docs/brief.md](./docs/brief.md) で管理する。

## 目的・ゴール / マイルストーン (Goals / Milestones)
1. 一次情報源をauditし、比較可能な指標を定義する。
2. provenanceを保持する収集・正規化pipelineを作る。
3. 分子・分母・算式・出典・不一致を毎回示し、source pairごとの参考比率としてGitHubで公開する。

## 手法・アプローチ (Approach)
primary regional referenceは日本国籍ではなく、日本に居住する全住民とする。分子と分母の組合せごとにindicatorを別定義し、両方のofficial definitionを保持し、観測できる組合せだけを単純計算して不一致を表示する。projectが導出した比率をofficialまたは正確な`犯罪率`とは呼ばない。nationality viewはsecondaryな記述表示であり、集団の本質や個人riskのlabelではない。

## 使い方 / 進め方 (Usage)
project-local environmentを作り、development dependencyとpackageをinstallする。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

検証済みのquality gateを実行し、complete offline pipelineを確認する。

```bash
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
.venv/bin/nca-pipeline --help
```

registryにpinしたofficial editionをregistered HTTPS URLから取得する。

```bash
.venv/bin/nca-acquire --source-id S08
.venv/bin/nca-acquire --source-id S15  # 全体の都道府県別crime context
.venv/bin/nca-acquire --source-id S16  # 10月1日総人口context
.venv/bin/nca-acquire --source-id S08 --refresh  # remote contentを明示的に再確認
```

通常は既存validated editionをnetworkなしでreuseする。`--refresh`は再downloadし、同一内容をreuseし、hashが変われば停止する。成功時にはmachine-readable JSONLと人間向けCSVのartifact catalogも更新する。

validated catalog input全体から、timestamp付きのlabel/category mapping auditを生成する。

```bash
.venv/bin/nca-map-dimensions
```

JSONL、CSV、provenance付きsummaryを`data/processed/_mappings/<timestamp>_dimension_mapping/`へ出力する。mapping statusは、犯罪分子と人口分母の統計的整合性を意味しない。

validated catalogとlatest reviewed mappingからtimestamp付きindicator data productを生成する。

```bash
.venv/bin/nca-build-indicators
```

immutableなJSONL／CSV recordとprovenance付きsummaryを`data/processed/_indicators/<timestamp>_indicators/`へ出力し、`latest.json`をatomicに更新する。計算値は`公表統計由来の参考比率`であり、officialまたは正確な`犯罪率`ではない。current outputはapproved non-suppressing warning heuristicとして、`small_number_warning_policy`、row-level `small_number_warning_flags`、`default_ranking_excluded`も持つ。

S15 / S16をpinした全住民regional-context productを生成する。

```bash
.venv/bin/nca-build-all-resident-context
```

immutableなJSONL／CSV recordとprovenance付きsummaryを`data/processed/_all_resident_context/<timestamp>_all_resident_context/`へ出力し、`latest.json`をatomicに更新する。認知件数／検挙件数／検挙人員の3系統を計算し、警察region／subregionのjoin不能行と、日本国籍prefecture分子・個別国籍 × 都道府県分子の非公表はrefusal rowとして同じrunに残す。

解決済みのlatest indicator productとall-resident productから、dashboard向けcompact exportを生成する。

```bash
.venv/bin/nca-build-compact-export
```

`output/compact_export/<timestamp>_compact_export/`へ`dashboard_export.json`、`summary.json`、export自体の`latest.json`を出力する。schema v2は同一source bytesをparse／hashし、row-to-definition IDを保持し、source summaryとrecordsを照合し、whitelistしたpublic source metadataだけを公開し、hash-closed pointerをatomicに更新する。future UIは後から移動したsource pointerやprivate local pathへ依存しない。

current pinned indicator runに対するcandidate denominator／numerator thresholdをauditする。

```bash
.venv/bin/nca-audit-small-numbers
```

immutableなsensitivity matrixと、参照時点の完全な`indicator_input_manifest.json`を`data/processed/_indicator_sensitivity/<timestamp>_small_number_sensitivity/`へ出力する。configは明示的に`policy_status=sensitivity_only`であり、実行してもcanonical indicator recordやUI warning ruleは変更・承認されない。

既に取得済みのlocal official artifactに対しては、timezone付き取得日時を指定してlow-level offline pipelineを実行する。

```bash
.venv/bin/nca-pipeline /path/to/official-file.xlsx \
  --source-id S14 \
  --retrieved-at 2026-08-30T09:00:00+09:00
```

pipelineはimmutable snapshotを`data/raw/<series>/<edition>/<timestamp>/`へ保存し、normalized JSONL、manifest、passしたquality reportを対応する`data/processed/` pathへ昇格する。registered direct URLからのdownloadは実装済みだが、新規公表editionの自動発見とschedule実行は未実装。low-level commandとして`nca-snapshot`、`nca-ingest`、`nca-validate`も利用できる。
