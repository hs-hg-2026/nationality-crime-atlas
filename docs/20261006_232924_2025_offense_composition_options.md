# 2025年 国籍等別×犯罪種類の更新候補と計画案

確認日: 2026-10-06。現状調査と計画案であり、取得・公開実装を完了した記録ではない。

## 結論

既存の「日本を含む26区分 × 刑法犯6区分」の2025年化を本線とする。
不足部分を推計せず、正式な後継表の公開確認と提供相談を進める手立てがある。
一方、既存パネルの置換には使えないが、2025年の補足表示に使える公的資料を2件確認した。
前回の「現在の取得データでは不足」は維持されるが、「補える資料が全くない」わけではない。

調査は一次資料優先の research-ops 手順による。PDFは関連表・凡例・正誤表の抽出本文を確認した。
PDF screenshotは画像として取得できなかったため、表の視覚配置の確認済みとはしない。

## 現行パネルの更新に必要なもの

- 現行契約: `config/offense_composition_contract.json`。2024年のS08表130とS15表3を使用。
- 対象は外国人全体の国籍等別内訳と、日本人等の算術残差。
- 凶悪犯・粗暴犯・窃盗犯・知能犯・風俗犯・その他の刑法犯の6区分。
- 件数と人員をそれぞれ保持する。総数と6区分合計を照合する。
- 日本人等の参考値には、同年・同指標・同犯罪区分・対応する範囲の「全国総数 − 外国人全体」が必要。
- 2025年の国籍掲載基準・中国等の範囲・不明／その他の分類を確認し、26行への無条件な押し込みはしない。

### 図表3-13の検証

- [公表一覧](https://www.npa.go.jp/publications/statistics/kikakubunseki/)
- [確定値版の本文](https://www.npa.go.jp/publications/statistics/kikakubunseki/r7jyousei_shuusei.pdf): 冊子59頁、PDF index 63。
- [CSV](https://www.npa.go.jp/publications/statistics/kikakubunseki/r7toukeisotai0313.csv): HTTP取得成功。2,890 bytes、CP932、CSV parserで39 logical rows。
- 確認時のCSV SHA-256: `097bf7096ce5f393645f658a9801b9f83374f07f08bdac9706f1391c8edb28c6`。正式なregistry pinには未登録。
- 総数＋5国籍 × 2年 × 件数／人員の24通りで、6区分合計と刑法犯総数が一致した。
- 独立した検証agentもPDF本文から24通りの一致、対象範囲、国籍列、凡例を確認した。CSV bytesは主agentのみ確認。
- 本文凡例114〜115頁では来日外国人の除外範囲が示され、中国は原則として台湾・香港等を含まない。
- [正誤表](https://www.npa.go.jp/publications/statistics/kikakubunseki/r7seigohyou.pdf)は国際会議参加機関数の訂正であり、図表3-13への訂正ではない。
- 6区分のみで構成比を作る。殺人・強盗や「うち万引き」等を親区分と混ぜて合算しない。

- [e-Stat公式公表ページ](https://www.e-stat.go.jp/stat-search/files?stat_infid=000040410682)

- 第12表の中国は台湾・香港等を含む。図表3-13とは定義が違うため同一の中国行として結合しない。
- 第12表の「総数」は対象とする重要犯罪・重要窃盗犯の範囲であり、刑法犯全体の総数ではない。
- PDFで内容は確認済みだが、ローカルXLSの第12表のセル構造・抽出・品質検証は未実施。

## 推奨する順番（未実装）

1. **更新に必要な表の仕様と候補の対応表を固定する。** 外国人全体／来日外国人、犯罪範囲、国籍範囲、件数／人員、年を明示。既存26区分更新用と補足用を分ける。本書が初期案。
2. **候補原本を正式に保存・抽出できるようにする。** 図表3-13を新editionとして登録・hash固定・immutable取得する。S02原本を変更せず、第12表用のparser／fixture／quality gateを別に追加する。既存製品の値は変更しない。
3. **正式な後継表の公表確認と問い合わせを準備する。** 年間詳細版の公式一覧・e-Statで表130相当を確認する。未発見なら公表予定・既存集計の提供可否を公式窓口へ相談する。送信はユーザー承認後。
4. **本線／補足の表示を分けて実装する。** 本線は必要な内訳取得後に2025年を追加。先行補足は希望がある場合だけ別パネルにし、掲載5国籍に限定される理由と未掲載を明示する。日本を同条件で計算できなければ「未算出」と理由を残す。
5. **継続確認を再起動に耐える形で残す。** 最終確認日・候補URL・公開待ち項目・次の確認日を追跡する。定期確認は提案であり、schedulerは未設定。正式な公表日を推測しない。

本計画案は、既に合意している2025年の地域別表示 → 人口当たり時系列の実装優先順位を変更しない。

## 採用時に守ること

- 全国総数から来日外国人だけを引いて日本人と呼ばない。
- 外国人全体を来日外国人＋永住者等の一部資料で復元できると仮定しない。
- 未掲載は0ではなく未取得／未公表として保持する。
- 特定犯罪だけを100%化して刑法犯全体の構成と呼ばない。
- 定義変更をまたぐ時系列は出典・変更点を表示し、互換性は別途reviewする。
- 凶悪犯以外を一律「軽犯罪」と扱わない。構成比は集団や個人の危険性・因果の判断ではない。
