# v0.3.0 — 国籍等別の5年時系列比較

`v0.3.0`は、日本を含む国籍等別の全国値について、2020–2024年の変化を同じ画面で確認できるようにしたreleaseです。

## 主な変更

- 日本を含む26区分 × 2020–2024年 × 検挙件数／検挙人員の260行を追加。220行を算出し、対応する人口区分を作れない40行は理由付きの`未算出`として保持。
- 26区分の人口1,000人当たり参考比率を、低値の青から高値の橙へ変化するheatmapで表示。最小・中間・最大値、未算出、色に良否の意味がないことを常設表示。
- 各区分の5年変化を行内で標準化し、ユークリッド距離・平均連結法による階層クラスタリングで似た変化パターンを近くに配置。年は時系列順を維持し、cluster順は危険度や順位を表さないことを明記。
- 日本人等の算術残差参考値を橙の破線で常時表示し、選択した国籍等を青の実線で比較。Y軸は選択中metricの全26区分・全5年を基準に0–11へ固定し、0, 2, 4, 6, 8, 10の共通目盛りを使用。
- `その他`の3区分を公表地域付きで区別し、選択した2区分の分子、分母、参考比率、注意点、未算出理由を年別表で確認可能にした。
- 公開dashboard bundleをschema v9へ更新。29件のsanitized source metadataと、国籍等別時系列260行を収録。

## 数値を読むときの注意

- 表示する人口当たりの値は、異なる公表統計を機械的に組み合わせた「公表統計由来の参考比率」です。犯罪を行う確率や公的な犯罪率ではありません。
- 日本人等の分子は、日本人等を含む全国総数から外国人全体を引いた算術残差です。直接公表された日本国籍の値ではありません。
- 外国籍等の犯罪統計の分子と在留外国人数の分母は、対象範囲や基準時点が一致しません。
- 公表されていない個別国籍 × 都道府県の分子は推計・按分していません。
- 階層クラスタリングは5年の変化パターンを探索するための表示順であり、犯罪の重大さ、良し悪し、因果関係、個人のriskを示しません。
