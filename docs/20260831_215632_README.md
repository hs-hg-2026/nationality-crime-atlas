# Collection and Visualization of Crime Statistics and Resident Population by Prefecture and Nationality

Verify trustworthy data sources; regularly collect nationwide crime statistics and resident populations by nationality, prefecture, and region; and publish counts plus reproducible public-data-derived reference ratios on GitHub.

日本語版: [README.ja.md](./README.ja.md)

## Background
Public data on resident populations and crime statistics are fragmented across publishers and may not share the same geographic, temporal, or nationality definitions. The detailed framing and cautions are maintained in [docs/brief.md](./docs/brief.md).

## Goals / Milestones
1. Audit primary sources and define comparable metrics.
2. Build a provenance-preserving collection and normalization pipeline.
3. Publish counts and source-pair-specific reference ratios, always showing their numerator, denominator, formula, provenance, and mismatches.

## Approach
Treat each numerator/denominator pairing as a separately named indicator. Preserve both official definitions, calculate only observable combinations, expose mismatches, and never present a project-derived ratio as an official or exact crime rate.

## Status
M0 and M1 are complete. On 2026-08-30, the M2 offline core, Deep Research triage, source registry v2, safe HTTPS acquisition, generated artifact catalog, and current formal production ingestion were completed. Registry v2 separates four source series from five immutable editions; `nca-acquire` downloads to temporary storage and promotes only artifacts that pass size, format, pinned SHA-256, parser, and source-specific quality checks.

All five current editions are now stored under `data/raw/` and `data/processed/` with zero duplicates and zero quality errors: 33 Table 130 records, 30 Table 131 records, 360 Table 13 records, 444,173 population records for 2024 year-end, and 468,641 population records for 2025 year-end. The generated JSONL/CSV catalog maps every local artifact to its publisher, official URL, period, retrieval time, hash, processing path, and quality status. Re-running an edition reuses the validated snapshot without network access; `--refresh` re-downloads it and still reuses identical content.

The M2 canonical dimension baseline is also complete. Across all 913,237 normalized input rows, `nca-map-dimensions` generated 612 distinct source-label mappings: 578 matched, 26 ambiguous, and 8 unmatched. All 47 NPA prefecture labels map one-to-one; police regions/subregions, source-region totals, and the NPA composite labels `中国` and `韓国・朝鮮` remain explicitly ambiguous. Context-specific `その他` buckets and `国籍不明` remain unmatched. A matched label is only a category crosswalk and does not assert statistical compatibility between a numerator and denominator.

The current-edition M2 baseline is complete, and M3 is now in progress. Indicator contract schema v2 defines 10 publication contracts for the six conceptual X/Y/Z × cases/persons combinations; X/Y each have separate exact and as-published crosswalk policies. The current validated output contains 290 records: 250 calculated and 40 explicitly refused. Every record exposes the raw numerator and denominator, unscaled quotient, provisional display multiplier, source pair, period/scope/geography context, mismatch flags, calculation status, and `statistical_compatibility=not_established`. The Z output contains 47 prefectures for each of cases and persons while retaining `police_reporting_area_unresolved`. Each required processed input must match both its processed run manifest and an independently version-controlled SHA-256 pin in the indicator contract.

The M3 small-number sensitivity audit is complete. A reproducible analyzer now compares denominator thresholds from 100 to 50,000 and numerator thresholds from 1 to 50 without treating them as publication rules. Current evidence supports a proposed two-axis, non-suppressing warning policy: denominator below 1,000 and numerator below 20. This proposal is not an official crime-statistics reliability standard and has not yet been applied to the canonical indicator output. The next M3 gate is approval of that policy, followed by the permanent interpretation note and primary UI policy/scale. Automated catalog discovery, scheduling, and historical backfill remain pending. The current suite has 80 passing tests, no skips, and 84.27% total coverage with branch measurement enabled.

## Usage
Create a project-local environment and install the package with development dependencies:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

Run the verified quality gate and inspect the complete offline pipeline:

```bash
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
.venv/bin/nca-pipeline --help
```

Acquire one pinned official edition directly from its registered HTTPS URL:

```bash
.venv/bin/nca-acquire --source-id S08
.venv/bin/nca-acquire --source-id S08 --refresh  # explicitly recheck remote content
```

The default command reuses an existing validated edition without network access. `--refresh` downloads again, reuses identical content, and stops on a hash change. A successful run updates the machine-readable JSONL and human-readable CSV artifact catalogs.

Generate a timestamped label/category mapping audit from every validated catalog input:

```bash
.venv/bin/nca-map-dimensions
```

This writes JSONL, CSV, and a provenance-rich summary under `data/processed/_mappings/<timestamp>_dimension_mapping/`. Mapping status deliberately does not imply that a crime numerator and population denominator are statistically compatible.

Generate a timestamped indicator data product from the validated catalog and latest reviewed mapping:

```bash
.venv/bin/nca-build-indicators
```

This writes immutable JSONL/CSV records and a provenance-rich summary under `data/processed/_indicators/<timestamp>_indicators/`, then atomically updates `latest.json`. Calculated values remain public-data-derived reference ratios; they are not official or exact crime rates.

Audit candidate denominator and numerator thresholds against the current pinned indicator run:

```bash
.venv/bin/nca-audit-small-numbers
```

This writes an immutable sensitivity matrix under `data/processed/_indicator_sensitivity/<timestamp>_small_number_sensitivity/`. Its config is explicitly `policy_status=sensitivity_only`; running it does not change canonical indicator records or approve a UI warning rule.

For an already acquired local official artifact, run the lower-level offline path with a timezone-qualified retrieval timestamp:

```bash
.venv/bin/nca-pipeline /path/to/official-file.xlsx \
  --source-id S14 \
  --retrieved-at 2026-08-30T09:00:00+09:00
```

The pipeline writes an immutable snapshot under `data/raw/<series>/<edition>/<timestamp>/` and promotes normalized JSONL plus manifests and a passing quality report under the matching `data/processed/` path. Direct registered-URL download is implemented; discovery of newly published editions and scheduled execution are not. Lower-level commands remain available as `nca-snapshot`, `nca-ingest`, and `nca-validate`.
