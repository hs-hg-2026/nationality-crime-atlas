# v0.4.0 — 2025年の全国検挙構成比を追加

2025年の全国検挙構成比を追加するminor releaseです。地域別・人口当たり参考比率・国籍等別時系列をすべて2025年へ更新するreleaseではありません。

## 画面の変更

- 「検挙全体に占める区分別の割合」を2015〜2025年へ延長。
- 検挙件数・検挙人員とも、外国人全体・来日外国人・両者の算術差分を表示。
- 日本人等は全国総数から外国人全体を引いた残差として、別panelと実数表に表示。
- 2025年の出典名を日本語表示し、従来年と掲載表が違うことを明記。
- 2015〜2024年の60行と、他の画面データ配列は変更なし。

## データ取得・算出処理

- 2025年犯罪統計概要S20–S23、国勢調査速報・外国人口推計S24–S25、人口確定値S26–S28、公式不詳補完参考値S29を登録・取得・正規化。
- 出典登録は19系列・44版。原本Excelと大きなprocessed dataはローカルに保持し、コード・契約・小型一覧を公開。
- 原数値の日本人・外国人・不詳、公式不詳補完値は別資料として保持。未掲載値を0で埋めない。
- 全国検挙構成比は2025年だけS21表3-3-1を使用。raw SHA-256、source ID、表・sheet・行・列を検査。
- 公開用data schema v9は継続。全国検挙構成比は66行、公開出典30件。

## 2025年の値

| 区分 | 検挙件数 / 全国301,055件 | 検挙人員 / 全国200,663人 |
|---|---:|---:|
| 外国人全体 | 22,917件 / 7.61% | 11,354人 / 5.66% |
| 来日外国人 | 17,614件 / 5.85% | 7,333人 / 3.65% |
| 外国人全体−来日外国人（差分） | 5,303件 / 1.76% | 4,021人 / 2.00% |
| 日本人等（算術残差） | 278,138件 / 92.39% | 189,309人 / 94.34% |

出典：[警察庁・令和7年刑法犯統計資料](https://www.npa.go.jp/toukei/seianki/R07/r07.zuhyosakuin.htm)、表3-3-1。
構成比は人口当たりの犯罪率ではありません。外国人全体−来日外国人は「普段から住む外国人」と同義ではありません。
