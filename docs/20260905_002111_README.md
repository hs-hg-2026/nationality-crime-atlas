# Nationality Crime Atlas for Japan

Official crime-related information is scattered across multiple agencies and documents, so finding the necessary values and organizing them for comparison is not straightforward. This project collects and organizes those public crime and population statistics, then visualizes them together with their sources and definition differences. It also shows unavailable calculations explicitly and does not judge whether values are good or bad, infer causes, or make value judgments about groups or individuals.

[日本語](./README.ja.md)

## Background

Crime numerators and population denominators are published by different agencies and often differ in geography, date, population scope, and nationality grouping. Showing nationality labels without that context can encourage misleading impressions. This project therefore keeps the concrete public values visible, makes incompatible or unavailable combinations explicit, and leaves causal or moral judgments outside the visualization.

## Goals / Milestones

1. Inventory and verify primary official sources.
2. Acquire immutable raw artifacts and build reproducible normalized data products.
3. Publish counts, formulas, sources, mismatch flags, warnings, and refusals together.
4. Visualize an all-resident regional context and a separate nationwide nationality comparison.
5. Add historical editions, year-over-year stability checks, and scheduled updates.

## Approach

- The primary regional view uses the total population residing in Japan, including Japanese and foreign residents.
- The secondary nationwide section includes a Japanese-inclusive cleared-person comparison plus eight selectable published foreign-nationality perspectives. When a compatible Japanese numerator is unavailable, Japan remains visible as an explicit refusal rather than disappearing.
- The Japanese numerator is a project-derived residual: all-person criminal-code cleared persons minus all-foreign criminal-code cleared persons. It is labeled as a reference estimate, never as a directly published Japanese value.
- Regional context is displayed per 100,000 total residents; nationwide nationality comparison is displayed per 1,000 corresponding residents. Raw numerators and denominators remain available.
- The offense-composition view shows all 26 nationality categories, including Japan, across six mutually exclusive criminal-code groups as a heatmap and a 100% stacked chart. It supports cleared persons / cleared cases and source / hierarchical-cluster ordering; cluster order is exploratory, not a danger ranking.
- `Recognized cases − cleared cases` is available as a signed same-year count and as a share of recognized cases. It is explicitly not called an unresolved count or rate because current-year clearances may include cases recognized in earlier years.
- The dashboard opens with a plain-Japanese explanation of its purpose, what each view can show, what it cannot establish, a short glossary, in-page navigation, and links to the Japanese README and interpretation policy.
- Every computed value is called a `public-data-derived reference ratio`, not an official or exact crime rate.
- Unpublished `individual nationality × prefecture` crime numerators are not estimated or allocated.
- Small denominators and sparse numerators remain visible with warnings; they are not silently removed.

See [docs/interpretation_note.md](./docs/interpretation_note.md) for the permanent interpretation policy.

## Data layout

- `data/raw/`: immutable official downloads plus manifests; never overwritten.
- `data/processed/`: reproducible normalized and derived products; large outputs are ignored by Git.
- `data/processed/_catalog/artifacts.{jsonl,csv}`: compact source-to-artifact provenance catalog.
- `output/`: regenerable publication products.
- `web/public/data/`: hash-verified static dashboard bundle.
- `inbox/`: read-only user-provided research inputs awaiting triage.

## Usage

Set up and verify the Python pipeline:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --no-build-isolation -e '.[dev]'
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
```

Acquire or reuse a registered edition and regenerate products:

```bash
.venv/bin/nca-acquire --source-id S17
.venv/bin/nca-map-dimensions
.venv/bin/nca-build-indicators
.venv/bin/nca-build-all-resident-context
.venv/bin/nca-build-nationality-comparison
.venv/bin/nca-build-offense-composition
.venv/bin/nca-build-compact-export
```

Run and verify the dashboard:

```bash
cd web
npm ci
npm run sync:data
npm run test:coverage
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run dev
```

Then open `http://localhost:3000/`. `npm run sync:data` only accepts the expected schema and writes a hash manifest; CI uses `npm run verify:data` before building.
