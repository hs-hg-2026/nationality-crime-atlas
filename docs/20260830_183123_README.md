# Collection and Visualization of Crime Statistics and Resident Population by Prefecture and Nationality

Verify trustworthy data sources; regularly collect nationwide crime statistics and resident populations by nationality, prefecture, and region; and publish counts plus reproducible public-data-derived reference ratios on GitHub.

日本語版: [README.ja.md](./README.ja.md)

## Background
Public data on resident populations and crime statistics are fragmented across publishers and may not share the same geographic, temporal, or nationality definitions. The detailed framing and cautions are maintained in [docs/brief.md](./docs/brief.md).

## Goals / Milestones
1. Audit primary sources and define comparable metrics.
2. Build a provenance-preserving collection and normalization pipeline.
3. Publish counts and source-pair-specific reference ratios, always showing their numerator, denominator, formula, provenance, and mismatches.

## Approach
Treat each numerator/denominator pairing as a separately named indicator. Preserve both official definitions, calculate only observable combinations, expose mismatches, and never present a project-derived ratio as an official or exact crime rate.

## Status
M0 and M1 are complete. The research-independent offline core of M2 was implemented and verified on 2026-08-30: three parsers, immutable raw snapshots, versioned source-quality profiles, and atomic snapshot → parse → validate promotion are working. M2 remains in progress until official source discovery/download, publication/revision metadata, canonical dimension mappings, and a formal production run are added.

The current suite has 38 passing tests with 86.71% total coverage (branch measurement enabled). Integrated smoke checks passed all four official artifacts with zero duplicates and zero quality errors: 468,641 population rows, 33 Table 130 rows, 30 Table 131 rows, and 360 Table 13 records. A second identical run was safely reused for every source.

## Usage
Create a project-local environment and install the package with development dependencies:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

Run the verified quality gate and inspect the complete offline pipeline:

```bash
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
.venv/bin/nca-pipeline --help
```

For an already acquired official artifact, run the full offline path with a timezone-qualified retrieval timestamp:

```bash
.venv/bin/nca-pipeline /path/to/official-file.xlsx \
  --source-id S14 \
  --retrieved-at 2026-08-30T09:00:00+09:00
```

By default, the command writes an immutable snapshot under `data/raw/` and promotes normalized JSONL plus manifests and a passing quality report under `data/processed/`. Automated official-source discovery and download are not implemented yet. Lower-level commands remain available as `nca-snapshot`, `nca-ingest`, and `nca-validate`.
