# v0.3.1 — 公開名称と検索表示の改善

`v0.3.1`は、公開サイトの名称を「日本の犯罪統計アトラス」に改め、検索結果やSNS共有で内容が伝わるようmetadataとpreview画像を整えるpatch releaseです。犯罪統計data、算出方法、公開用data schemaは変更しません。

## 主な変更

- 画面の主見出しと公開名称を「日本の犯罪統計アトラス」に統一。
- page titleを「日本の犯罪統計アトラス｜公表犯罪統計と人口統計を可視化」とし、地域・国籍等・犯罪種別・時系列、出典・定義差、未算出理由を扱うことをdescriptionへ明記。
- canonical URL、`index, follow`、Open Graph metadata、1 URLの`sitemap.xml`を追加。
- OGP画像を1200 × 630で更新し、新名称と既存の副題「公表統計を、定義差と出典とともに。」を表示。
- GitHub Pages artifact gateを拡張し、公開名称、title、description、canonical、robots、Open Graph metadata、sitemapの欠落や不一致を拒否。
- CI環境でのjsdom dashboard testの実行時間差に備え、Vitestのtest timeoutを30秒へ明示。
- GitHub Pagesはsubdirectoryで公開しているため、domain／subdomain rootを対象とするGoogleの`WebSite` site-name structured dataは追加していない。

## 変更しないもの

- 公開URLとrepository名
- 公開用data schema v9
- 犯罪統計・人口統計の数値、算出方法、注意表示
- 公開data SHA-256 `4219edb5c7ff75e52bae97452f4991f6e5852dd746cfca1d3dc9c4d62bd37f65`
