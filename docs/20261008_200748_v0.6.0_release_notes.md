# v0.6.0 — 2025年の国籍等別比較と来日外国人の犯罪構成

## 追加した表示

- 国籍等別の全国比較に2025年を追加し、初期表示にしました。2024年へ切り替えられます。
- 30区分について検挙件数／検挙人員、外国人全体／来日外国人を選択できます。120行のうち52行は参考比率を算出、68行は未算出として残します。日本は全国総数から外国人全体を差し引いた参考値で、別色で示します。
- 犯罪種類の2025年表示は、公式資料に掲載された来日外国人5国籍と別枠の来日外国人総数が対象です。6区分の数値付き2色ヒートマップ、100%積み上げ棒、実数・出典、階層クラスタリングを追加しました。
- 公式CSVの取得・検証と、追加データ専用のhash固定・公開物検査を追加しました。

## 残している区別と制約

- 2024年の全26区分の犯罪構成と、2020〜2024年の国籍等別時系列は保持します。対象範囲の異なる2025年を時系列へ黙って接続しません。
- 2025年の犯罪構成は外国人全体の内訳ではありません。日本の構成は今回の資料から算出できず、未算出と明示します。
- 掲載基準、人口と犯罪統計の対象範囲・時点の違い、中国・韓国朝鮮の区分差、日本人人口の不詳除外を表示します。未掲載を0と扱いません。
- 算出値は公表統計由来の参考比率です。正式な犯罪率、原因、集団や個人の危険度を判定するものではありません。
