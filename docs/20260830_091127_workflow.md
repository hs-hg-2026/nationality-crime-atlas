| Phase | 入力 | 作業 | 出力 |
|---|---|---|---|
| M0 | project目的、用語候補 | 分子・分母・国籍・地理・期間を定義 | metric specification |
| M1 | source候補 | 一次資料、定義、coverage、更新頻度をaudit | source inventory / availability matrix |
| M2 | 検証済みsource | download、provenance保存、共通schema化 | raw snapshot / processed dataset |
| M3 | population、crime statistics | 整合性test、rate計算、非比較可能flag | validated data product |
| M4 | validated data product | map・filter・注記・source導線を実装 | GitHub上のvisualization |
| M5 | source公開schedule | 定期取得、変更検知、公開gate | 継続更新されるdashboard |

詳細な達成条件とサブマイルストーンは [brief.md](./brief.md) を参照。
