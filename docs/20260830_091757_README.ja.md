# 都道府県別・国籍別の犯罪統計と在留人口の収集・可視化

信頼できる情報源を検証し、全国・都道府県別・地域別の国籍別在留人口と犯罪統計を定期収集・更新して、人口当たりの比率をGitHub上で可視化する。

English: [README.md](./README.md)

## 背景 (Background)
在留人口と犯罪統計の公開情報は公表主体が分かれ、地理・期間・国籍区分が一致しない可能性がある。詳しい問題設定と注意点は [docs/brief.md](./docs/brief.md) で管理する。

## 目的・ゴール / マイルストーン (Goals / Milestones)
1. 一次情報源をauditし、比較可能な指標を定義する。
2. provenanceを保持する収集・正規化pipelineを作る。
3. 限界を明示しながら、件数と妥当な場合に限ったpopulation-normalized indicatorをGitHubで公開する。

## 手法・アプローチ (Approach)
データ収集前に分子・分母・地理・国籍区分・対象期間を定義し、情報源audit、取得prototype、rate検証、可視化、定期更新の順に進める。

## 現状 (Status)
2026-08-30時点でM1（source availability audit）は完了。`国籍・地域 × 都道府県` の人口分母は検証できた一方、routine official source の `国籍 × 都道府県` 犯罪分子は確認できなかった。現在地はM0のpublication rule再確定で、count-only / provenance-first のMVPは進められるが、`国籍 × 都道府県` の犯罪率は現時点では進めない。詳細は [docs/20260830_085603_source_availability_audit.md](./docs/20260830_085603_source_availability_audit.md) と [docs/brief.md](./docs/brief.md) を参照。
