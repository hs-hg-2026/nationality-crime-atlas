# 根拠付き用語集の実装メモ

## 位置づけ

`v0.2.0`公開後の実装順は、次のとおりとする。

1. 公開サイトからGitHub Issuesへ移る導線（実装済み）
2. 可視化要望／不具合報告のissue template
3. 公式定義と根拠を確認できる用語集
4. 2020–2024年の地域別・国籍等別・犯罪種類別panel

## 用語集の必須項目

- サイト内の表記
- 短く平易な説明
- 公的機関が公表した定義の必要最小限の引用
- 公表機関、資料名、URL、確認日
- その定義が適用されるsource・統計・期間
- 似た用語との関係と、してはいけない読み替え

画面では用語の初出または主要な注意書きから対応する用語集anchorへ移動できるようにする。色やhoverだけに依存せず、keyboardとscreen readerでも意味と移動先が分かる表現とする。

## 最初の対象：来日外国人

警察庁の統計では、日本にいる外国人のうち、いわゆる定着居住者（永住権を有する者等）、在日米軍関係者、在留資格不明の者を除いた人を「来日外国人」としている。そのため、「短期滞在者のみ」や「新しく日本に来た人」と読み替えない。

確認した根拠：

- [警察庁「犯罪統計資料（対前年同期比較）」](https://www.npa.go.jp/toukei/keiji35/new_hanzai07.htm)の「用語の解説」「（4）来日外国人」。2026年9月6日に記載を確認。
- [法務省法務総合研究所「平成16年版 犯罪白書」第1編第2章第2節2](https://hakusyo1.moj.go.jp/jp/48/nfm/n_48_2_1_2_2_2.html)。警察庁の統計定義による同内容の記載を2026年9月6日に確認。

### 平易な説明と実例の確認原則

- userからの具体的な確認事項は、「visaを取得して来日した人で、visaが有効な人と切れている人の両方を含むのか」である。これは現時点の公式定義文だけでは確定しないため、未確認の問いとして保持する。
- 「来日外国人」は除外対象で定める警察統計上の区分であり、visaの有効／失効だけで直接言い換えない。
- 警察庁、法務省、出入国在留管理庁の公式QA、用語解説、白書などから、具体的な対象例／除外例を探す。公式な実例が確認できた場合だけ、非網羅的な例であることと、適用される統計／期間を併記して用語集に載せる。
- 公式な実例が見つからない場合は、公式定義とprojectの平易な説明を明確に分け、後者を公式の説明として表示しない。

## 続けて検討する用語

- 外国人全体
- 定着居住者
- 在留外国人
- 日本人等（全国総数−外国人全体の算術残差）
- 認知件数、検挙件数、検挙人員
- 包括罪種、重要犯罪、重要窃盗犯
- 公表統計由来の参考比率

用語ごとに定義のsourceと適用範囲を別々に検証し、異なる機関の似た用語を自動的に同一視しない。
