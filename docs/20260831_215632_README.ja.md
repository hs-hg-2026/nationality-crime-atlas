# 都道府県別・国籍別の犯罪統計と在留人口の収集・可視化

信頼できる情報源を検証し、全国・都道府県別・地域別の国籍別在留人口と犯罪統計を定期収集・更新して、件数と公表統計から再現可能に導いた参考比率をGitHub上で可視化する。

English: [README.md](./README.md)

## 背景 (Background)
在留人口と犯罪統計の公開情報は公表主体が分かれ、地理・期間・国籍区分が一致しない可能性がある。詳しい問題設定と注意点は [docs/brief.md](./docs/brief.md) で管理する。

## 目的・ゴール / マイルストーン (Goals / Milestones)
1. 一次情報源をauditし、比較可能な指標を定義する。
2. provenanceを保持する収集・正規化pipelineを作る。
3. 分子・分母・算式・出典・不一致を毎回示し、source pairごとの参考比率としてGitHubで公開する。

## 手法・アプローチ (Approach)
分子と分母の組合せごとにindicatorを別定義する。両方のofficial definitionを保持し、観測できる組合せだけを単純計算し、不一致を表示する。projectが導出した比率をofficialまたは正確な`犯罪率`とは呼ばない。

## 現状 (Status)
M0とM1は完了。2026-08-30にM2のoffline core、Deep Research triage、source registry v2、安全なHTTPS acquisition、generated artifact catalog、current formal production ingestionを完了した。registry v2は4 source seriesと5 immutable editionを分離し、`nca-acquire`はtemporary storageへdownloadして、size、format、pinned SHA-256、parser、source-specific qualityを通ったartifactだけを昇格する。

current 5 editionはすべて`data/raw/`と`data/processed/`へ保存され、duplicate 0／quality error 0である。内訳は表130が33 record、表131が30 record、表13が360 record、2024年末人口が444,173 record、2025年末人口が468,641 record。generated JSONL/CSV catalogから、各local artifactのpublisher、official URL、period、取得日時、hash、processed path、quality statusを追跡できる。通常の再実行はnetworkなしでvalidated snapshotをreuseし、`--refresh`でも同一内容ならreuseする。

M2のcanonical dimension baselineも完了した。913,237 normalized input row全体から、`nca-map-dimensions`は612件のdistinct source-label mappingを生成した。内訳はmatched 578、ambiguous 26、unmatched 8。NPAの47都道府県labelはすべて1対1で対応し、警察region／subregion、source region total、NPAの複合label `中国`と`韓国・朝鮮`はambiguousのまま保持した。contextごとの`その他`と`国籍不明`はunmatchedとした。matchedはcategory crosswalkだけを意味し、分子・分母の統計的整合性を保証しない。

current editionを対象とするM2 baselineは完了し、現在地はM3である。indicator contract schema v2は、6つのconceptual case（X/Y/Z × cases/persons）を10個のpublication contractとして定義した。X/Yはexactとas-publishedのcrosswalk policyを別contractにしている。current validated outputは290 recordで、250件を計算し、40件を理由付きで拒否した。各recordからraw numerator／denominator、unscaled quotient、provisional display multiplier、source pair、period／scope／geography context、mismatch flag、calculation status、`statistical_compatibility=not_established`を追跡できる。Zはcases/personsそれぞれ47都道府県を持ち、`police_reporting_area_unresolved`を維持する。required processed inputは、processed run manifestとindicator contract内の独立したversion-controlled SHA-256 pinの両方に一致しなければ計算へ進まない。

M3のsmall-number sensitivity auditは完了した。reproducible analyzerでdenominator 100–50,000、numerator 1–50のcandidate thresholdを比較し、publication ruleとは分離した。current evidenceからは、denominator 1,000未満とnumerator 20未満を別々に示すnon-suppressing warning policyを提案する。これはofficial crime-statistics reliability standardではなく、canonical indicator outputへはまだ適用していない。次のM3 gateはこのpolicyの承認で、その後に常設interpretation noteとprimary UI policy／scaleを確定する。新editionのautomatic catalog discovery、schedule実行、historical backfillは未実装。現在のtestは80件すべて成功、skip 0、branch計測を有効にしたtotal coverageは84.27%。

## 使い方 / 進め方 (Usage)
project-local environmentを作り、development dependencyとpackageをinstallする。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

検証済みのquality gateを実行し、complete offline pipelineを確認する。

```bash
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
.venv/bin/nca-pipeline --help
```

registryにpinしたofficial editionをregistered HTTPS URLから取得する。

```bash
.venv/bin/nca-acquire --source-id S08
.venv/bin/nca-acquire --source-id S08 --refresh  # remote contentを明示的に再確認
```

通常は既存validated editionをnetworkなしでreuseする。`--refresh`は再downloadし、同一内容をreuseし、hashが変われば停止する。成功時にはmachine-readable JSONLと人間向けCSVのartifact catalogも更新する。

validated catalog input全体から、timestamp付きのlabel/category mapping auditを生成する。

```bash
.venv/bin/nca-map-dimensions
```

JSONL、CSV、provenance付きsummaryを`data/processed/_mappings/<timestamp>_dimension_mapping/`へ出力する。mapping statusは、犯罪分子と人口分母の統計的整合性を意味しない。

validated catalogとlatest reviewed mappingからtimestamp付きindicator data productを生成する。

```bash
.venv/bin/nca-build-indicators
```

immutableなJSONL／CSV recordとprovenance付きsummaryを`data/processed/_indicators/<timestamp>_indicators/`へ出力し、`latest.json`をatomicに更新する。計算値は`公表統計由来の参考比率`であり、officialまたは正確な`犯罪率`ではない。

current pinned indicator runに対するcandidate denominator／numerator thresholdをauditする。

```bash
.venv/bin/nca-audit-small-numbers
```

immutableなsensitivity matrixを`data/processed/_indicator_sensitivity/<timestamp>_small_number_sensitivity/`へ出力する。configは明示的に`policy_status=sensitivity_only`であり、実行してもcanonical indicator recordやUI warning ruleは変更・承認されない。

既に取得済みのlocal official artifactに対しては、timezone付き取得日時を指定してlow-level offline pipelineを実行する。

```bash
.venv/bin/nca-pipeline /path/to/official-file.xlsx \
  --source-id S14 \
  --retrieved-at 2026-08-30T09:00:00+09:00
```

pipelineはimmutable snapshotを`data/raw/<series>/<edition>/<timestamp>/`へ保存し、normalized JSONL、manifest、passしたquality reportを対応する`data/processed/` pathへ昇格する。registered direct URLからのdownloadは実装済みだが、新規公表editionの自動発見とschedule実行は未実装。low-level commandとして`nca-snapshot`、`nca-ingest`、`nca-validate`も利用できる。
