# 日本の犯罪統計アトラス

犯罪に関する公的な情報は複数の機関や資料に分散しており、必要な数値へたどり着き、比較できる形に整理することは容易ではありません。このプロジェクトは、それらの公表情報を収集・整理し、犯罪統計と人口統計を出典や定義の違いとともに可視化します。算出できない項目も省略せず示し、数値の良し悪しの評価、原因の推定、集団や個人に対する価値判断は行いません。

[English](./README.md)

## 背景

犯罪件数・検挙人員と人口は、異なる行政機関から、異なる地域・時点・対象範囲・国籍区分で公表されています。その違いを示さず国籍名と数字だけを並べると、事実に結びつかない印象を生むおそれがあります。このプロジェクトでは、公表された具体的な値を隠さず、比較できない組み合わせや非公表の項目も明示し、因果関係や価値判断を可視化へ持ち込みません。

## 目的・マイルストーン

1. 公的機関の一次資料を一覧化し、内容と取得先を確認する。
2. 元データを変更せず保存し、再現可能な整形済みデータを作る。
3. 件数、計算式、出典、定義の違い、注意点、算出しなかった理由を一緒に公開する。
4. 日本人と外国人を合わせた地域全体と、別枠の全国・国籍等別比較を可視化する。
5. 複数年のデータ、年ごとの安定性確認、定期更新を追加する。

## 手法・考え方

- 最初の地域表示で使う「総人口」は、日本人と外国人を含む、日本に住むすべての人を指します。
- 全国・国籍等別の表示では、日本を含む刑法犯の検挙人員と検挙件数の比較に加え、外国人について公表されている8種類の数え方を選べます。同じ条件の日本の犯罪件数・人員がない場合も、日本を一覧から消さず「未算出」と表示します。
- 日本の刑法犯検挙人員と検挙件数は、対応する全住民の値から全外国人の値を差し引いた参考値です。日本について直接公表された値とは呼びません。
- 地域表示は全住民10万人当たり、全国の国籍等別表示は対応人口1,000人当たりです。割る前の犯罪件数・人員と人口も確認できます。
- 全国・国籍等別のグラフは、算出できる全区分を参考比率の高い順に示し、未算出を0とせず一覧に残します。日本の残差参考値は別色で、全表には実数と参考比率の両方を残します。
- 2020–2024年の国籍等別表示では、日本を含む全26区分を、数値凡例付きの青から橙の2色heatmapで示します。行は、区分ごとに標準化した5年間の変化パターンを平均連結法による階層クラスタリングで並べ、全期間未算出の区分は末尾に残します。検挙件数／検挙人員を切り替え、日本の残差参考値と選んだ1区分を2本の折れ線と年別の分子・分母・参考比率で比較できます。Y軸は0から始め、全26区分の最大値を切り上げた共通上限を使います。未算出は0で補いません。
- 2015–2025年について、日本人等を含む全国の刑法犯検挙全体に占める「外国人全体」「来日外国人」と、両者の算術差分の割合を、検挙件数と検挙人員の両方で示します。差分は「普段から住む外国人」と同義ではなく、定着居住者のほか在日米軍関係者や在留資格不明者も含み得ます。いずれも検挙全体の構成比であり、人口当たりの犯罪率ではありません。
- 別の2015–2025年表示では、日本人等と外国人全体を別panelにし、検挙件数／検挙人員、分母に使った人口、人口1,000人当たりの参考比率を同じ年軸で示します。日本人等の分子は算術残差です。外国人全体の犯罪統計上の分子と在留外国人数の分母は対象範囲が一致しません。2015年の外国人分子は表示しますが、分母が未登録のため参考比率は「未算出」とします。2025年は国勢調査の日本人人口原数値を使い、日本人・外国人の別の不詳を分母に含めません。人口推計からの資料変更を常設表示し、不詳補完値へ黙って置き換えません。
- 犯罪の種類は、日本を含む全26区分について、重ならない刑法犯6区分の内訳を、色の濃淡による表と100%積み上げ棒で表示します。検挙人員／検挙件数、元データの掲載順／似た構成を近くする順を切り替えられます。似た構成を近くする順は探索用であり、危険度の順位ではありません。
- 「認知件数−検挙件数」は、同じ年の差と、認知件数に占める割合として表示します。その年の検挙には前年以前に認知された事件が含まれることがあるため、「未解決件数」「未解決率」とは呼びません。
- 異なる公表統計を組み合わせて計算した値は「公表統計由来の参考比率」と呼び、公的機関が算出した正式な犯罪率とは区別します。
- 公表されていない「国籍等別かつ都道府県別」の犯罪件数・人員は、推計や人口比での割り振りをしません。
- 人口や犯罪件数・人員が少ない区分も隠さず、値が変動しやすいという注意を添えます。
- 画面の冒頭に、このサイトの目的、分かること、分からないこと、用語説明、ページ内メニューを置き、この日本語READMEと数字の読み方へ直接移動できるようにしています。

常設の解釈方針は [数字の読み方](./docs/interpretation_note.md) を参照してください。

## データの配置

- `data/raw/`：公的機関から取得した元データと取得記録。上書きしません。
- `data/processed/`：コードで再生成できる整形済み・計算済みデータ。大容量のものはGit管理外です。
- `data/processed/_catalog/artifacts.{jsonl,csv}`：出典とローカルデータの対応一覧。
- `output/`：コードで再生成できる公開用データなどの出力。
- `web/public/data/`：hashを確認した、画面表示用の静的データ。
- `inbox/`：ユーザーが持ち込んだ未整理資料。内容を変更せず扱います。

## 使い方

Pythonの処理環境を作り、検証する：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --no-build-isolation -e '.[dev]'
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
```

登録済みデータを取得または再利用し、各データを再生成する：

```bash
.venv/bin/nca-acquire --source-id S17
.venv/bin/nca-build-indicators
.venv/bin/nca-map-dimensions --source-id S14_2024_12 --source-id S20 --source-id S26 --output-root data/processed/_regional_mappings
.venv/bin/nca-build-all-resident-context
.venv/bin/nca-build-nationality-comparison
.venv/bin/nca-build-offense-composition
.venv/bin/nca-build-clearance-share-trend
.venv/bin/nca-build-clearance-population-trend
.venv/bin/nca-build-nationality-trend
.venv/bin/nca-acquire --source-id S30
.venv/bin/nca-build-nationality-2025
.venv/bin/nca-build-compact-export
```

画面を検証・起動する：

```bash
cd web
npm ci
npm run sync:data
npm run test:coverage
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run dev
```

その後、`http://localhost:3000/` を開きます。`npm run sync:data` は想定したデータ形式だけを受け付け、hash記録を生成します。自動検査ではbuild前に `npm run verify:data` を実行します。
