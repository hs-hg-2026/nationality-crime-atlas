| Phase | 入力 | 作業 | 出力 |
|---|---|---|---|
| M0 | project目的、用語候補、M1 findings | initial framing後、exact rateを目標にせずsource pairごとの参考比率を確定 | publication policy / indicator contract |
| M1 | source候補 | 一次資料、定義、coverage、更新頻度をaudit | source inventory / availability matrix |
| M0 decision gate | M1 findings、user decision | raw count＋公表統計由来の参考比率、非推計、表示labelを確定 | approved publication rules |
| M2 | 検証済みsource | download、provenance保存、共通schema化 | raw snapshot / processed dataset |
| M3 | population、crime statistics | source pair別の単純計算、provenance・mismatch flag検証 | validated indicators |
| M4 | validated data product | map・filter・注記・source導線を実装 | GitHub上のvisualization |
| M5 | source公開schedule | 定期取得、変更検知、公開gate | 継続更新されるdashboard |

確定したpublication rule:

- 完全に一致する分子・分母の取得をproject milestoneやM2のblockerにしない。
- raw countに加え、利用可能な公表統計を単純に割った値を`公表統計由来の参考比率`として表示してよい。
- indicatorごとに分子・分母・算式・出典・期間・地理・母集団の不一致を表示し、officialまたは正確な`犯罪率`とは呼ばない。
- 存在しない`個別国籍 × 都道府県`分子は推計しない。
- 警察庁照会・都道府県警auditはdata enrichment trackであり、MVPのgateにしない。
