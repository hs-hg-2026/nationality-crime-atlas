# v0.2.0 — 全国時系列と人口当たり参考比率

`v0.2.0`は、公的機関に分散する過去年の犯罪統計と人口統計を追加し、全国値の2015–2024年の変化を確認できるようにしたreleaseです。

## 主な変更

- 2015–2024年の刑法犯検挙全体に占める「外国人全体」「来日外国人」「両者の算術差分」の構成比を、検挙件数と検挙人員の両方で追加。
- 日本人等と外国人全体を別panelに分け、検挙件数／検挙人員、分母の参照人口、人口1,000人当たりの公表統計由来の参考比率を同じ年軸で表示。
- 過去年の公式資料を追加し、9 source series／34 immutable editionsを検証済みcatalogで管理。
- 公開dashboard bundleをschema v8へ更新。人口当たり時系列40行と検挙構成比時系列60行を収録し、21件の出典metadataを掲載。
- 「日本を含む国籍等別の全国比較」の選択肢を検挙件数→検挙人員の順に統一。
- Python compact export、JavaScript publication gate、frontend view modelの3層で、年／指標／対象区分の欠落や危険な定義変更を拒否するsemantic validationを強化。

## 数値を読むときの注意

- 表示する人口当たりの値は、異なる公表統計を機械的に組み合わせた「公表統計由来の参考比率」です。犯罪を行う確率や公的な犯罪率ではありません。
- 日本人等の分子は、日本人等を含む全国総数から外国人全体を引いた算術残差です。
- 外国人全体の犯罪統計の分子と在留外国人数の分母は、対象範囲が一致しません。2015年は分子を表示しますが、対応分母が未登録のため参考比率を未算出としています。
- 「外国人全体−来日外国人」は算術差分であり、「普段から住む外国人」や「在留外国人」と同義ではありません。
