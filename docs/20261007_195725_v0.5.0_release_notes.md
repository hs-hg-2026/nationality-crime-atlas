# v0.5.0 — 2025年の地域別地図と人口当たり時系列を追加

取得済みの公的資料から、地域別表示と人口当たり検挙参考比率を更新するminor releaseです。すべての表示を2025年へ更新するものではありません。

## 画面の変更

- 全国＋47都道府県の地図・表を2025年へ更新。刑法犯認知件数・検挙件数・検挙人員と、全住民10万人当たりの参考比率を表示します。
- 認知件数と検挙件数の同年差も2025年へ更新。ただし未解決件数・未解決率とは呼びません。
- 「人口の変化と人口1,000人当たりの検挙」を2015〜2025年へ延長。日本人等の算術残差と外国人全体を別panelに表示し、両者でY軸上限・1.0刻みの目盛りを共通にします。
- 2025年の日本人人口は国勢調査の原数値を使用。日本人・外国人の別の不詳2,105,452人をこの分母に含めず、前年までの人口推計から資料が変わることを常設説明します。

## データと解釈の範囲

- 地域別の犯罪分子はS20、総人口はS26。地域の総人口は日本人・外国人と国籍区分の不詳を含みます。
- 全国の2025年検挙分子はS21表3-3-1。日本人等は全国総数−外国人全体の残差であり、直接公表された日本国籍の値ではありません。
- 日本人人口はS27原数値117,405,318人。在留外国人数はS19_2025の4,125,395人。不詳補完参考値S29へ黙って置き換えません。
- 年間の検挙と時点人口、外国人全体と在留外国人数の対象範囲は一致しません。計算結果は公表統計由来の参考比率であり、正式・正確な犯罪率や個人のriskを意味しません。
- 従来の人口時系列40行と、国籍等別比較・時系列・犯罪種類構成の既存配列は変更していません。
- 国籍等別比較・時系列と犯罪種類構成は2024年までです。2025年の部分的な国籍表を、旧26区分と同じものとして追加しません。
