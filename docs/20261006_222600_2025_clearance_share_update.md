# 2025年の全国検挙構成比を追加

更新日：2026年10月6日（日本時間）。ローカル実装・検証済み。push/releaseは未実施。

## 完了した範囲

「検挙全体に占める区分別の割合」を2015〜2025年へ延長した。
検挙件数・検挙人員の両方について、外国人全体、来日外国人、両者の算術差分を保持する。
日本人等の残差も従来通り別panel・実数表に表示する。11年 × 2指標 × 3範囲 = 66行。

2015〜2024年の60行は値・出典・注意事項を含め変更なし。他の画面データ配列も変更なし。
2025年だけS21を使う契約を追加し、出典切替を画面へ明記した。S21の出典名も日本語で表示する。
公開中のサイトはpushされるまで従来データのままである。

## 出典・実数・構成比

出典：[警察庁・令和7年の刑法犯に関する統計資料](https://www.npa.go.jp/toukei/seianki/R07/r07.zuhyosakuin.htm)、
[第3章の公式Excel](https://www.npa.go.jp/toukei/seianki/R07/r07_3.xlsx)、表3-3-1。
前回取得・公式refreshで検証した同一版を再利用し、今回は保存済みExcelのhashとセルを直接照合した。

| 区分 | 検挙件数 | 全国301,055件に占める割合 | 検挙人員 | 全国200,663人に占める割合 |
|---|---:|---:|---:|---:|
| 外国人全体 | 22,917 | 7.61% | 11,354 | 5.66% |
| 来日外国人 | 17,614 | 5.85% | 7,333 | 3.65% |
| 外国人全体−来日外国人（差分） | 5,303 | 1.76% | 4,021 | 2.00% |
| 日本人等（全国総数−外国人全体の残差） | 278,138 | 92.39% | 189,309 | 94.34% |

検挙件数はN4（全国）・N5（外国人全体）・N6（来日外国人）、検挙人員はN7・N8・N9。
同じsource IDでも対象範囲のセルは異なるため、出典componentの役割と参照セルを保存・検査する。
formula文字列はsource ID単位の略記であり、対象範囲を識別するにはcomponentを併せて読む。

これは検挙全体に占める構成比であり、人口当たりの犯罪率ではない。
来日外国人との差分を「在留外国人」「普段から住む外国人」と言い換えない。
日本人等は直接公表された日本国籍値ではなく算術残差。

再起動後も原本・契約・結果・最新pointerを保存した状態から継続できる。
通常のS21再取得は既存の検証済み版を再利用する。

```bash
.venv/bin/nca-acquire --source-id S21
.venv/bin/nca-build-clearance-share-trend
.venv/bin/nca-build-compact-export
cd web
npm run sync:data
npm run verify:data
```

再生成は新しい時刻付きrunを作成するため、出力ファイル全体のhashは変わり得る。
公式原本hash・実数・計算・出典対応は変わらない。
