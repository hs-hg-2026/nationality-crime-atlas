# 日本の国籍別犯罪統計 atlas

日本の公的な犯罪統計と人口統計を収集し、定義と出典を保持したうえで、件数と再現可能な`公表統計由来の参考比率`を可視化するprojectである。国籍を集団の本質的riskとして扱わない。

[English](./README.md)

## 背景 (Background)

犯罪の分子と人口の分母は異なる行政機関から公表され、地理・時点・population scope・国籍区分が一致しないことが多い。そのcontextなしに国籍labelだけを示すと、事実に結びつかない印象を生みうる。このprojectは、公表された具体値を隠さず、比較不能・非公表の組合せも明示し、因果や価値判断を可視化へ持ち込まない。

## 目的・ゴール / マイルストーン (Goals / Milestones)

1. official primary sourceをinventory化して検証する。
2. immutableなraw artifactを取得し、再現可能なnormalized data productを作る。
3. count、算式、source、mismatch flag、warning、refusalを一緒に公開する。
4. 全住民の地域contextと、別枠の全国・国籍等別比較を可視化する。
5. historical edition、year-over-year stability check、scheduled updateを追加する。

## 手法・アプローチ (Approach)

- primary regional viewの`総人口`は、日本人と外国人を含む日本の全住民を指す。
- secondaryな全国sectionは、日本を含む刑法犯検挙人員比較と、選択可能な8種類の公表外国人perspectiveを扱う。compatibleな日本人分子がないperspectiveでも、日本を消さずexplicit refusalとして表示する。
- 日本人の分子は、刑法犯検挙人員の全体から全外国人を差し引いたproject-derived residual（残差）である。directに公表された日本人値とはせず、`残差参考値`と明示する。
- 地域contextは全住民10万人当たり、全国の国籍等別比較は対応人口1,000人当たりで表示する。raw numerator／denominatorも残す。
- 犯罪類型構成は、日本を含む全26 categoryについて、mutually exclusiveな刑法犯6区分をheatmapと100%積み上げ棒で表示する。検挙人員／検挙件数、公表順／階層cluster順を切り替えられるが、cluster順は探索表示であり危険度順位ではない。
- `認知件数−検挙件数`は、符号付きの同年差分件数と認知件数に占める割合として表示する。当年の検挙には前年以前に認知した事件が含まれ得るため、`未解決件数`／`未解決率`とは呼ばない。
- 計算値はすべて`公表統計由来の参考比率`と呼び、officialまたは正確な`犯罪率`とは呼ばない。
- 非公表の`個別国籍 × 都道府県`犯罪分子は推計・按分しない。
- 小さい分母や少数の分子もwarning付きで表示し、silentに除外しない。

常設の解釈方針は [docs/interpretation_note.md](./docs/interpretation_note.md) を参照。

## Data配置 (Data layout)

- `data/raw/`: official downloadとmanifestのimmutable正本。上書きしない。
- `data/processed/`: 再生成可能なnormalized／derived product。大容量outputはGit管理外。
- `data/processed/_catalog/artifacts.{jsonl,csv}`: sourceとlocal artifactのcompactなprovenance catalog。
- `output/`: 再生成可能なpublication product。
- `web/public/data/`: hash検証済みのstatic dashboard bundle。
- `inbox/`: triage前のuser持ち込み資料。read-onlyとして扱う。

## 使い方 / 進め方 (Usage)

Python pipelineをsetup・検証する:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --no-build-isolation -e '.[dev]'
.venv/bin/python -m pytest --cov=nationality_crime_atlas --cov-report=term-missing
```

registered editionを取得またはreuseし、productを再生成する:

```bash
.venv/bin/nca-acquire --source-id S17
.venv/bin/nca-map-dimensions
.venv/bin/nca-build-indicators
.venv/bin/nca-build-all-resident-context
.venv/bin/nca-build-nationality-comparison
.venv/bin/nca-build-offense-composition
.venv/bin/nca-build-compact-export
```

dashboardを実行・検証する:

```bash
cd web
npm ci
npm run sync:data
npm run test:coverage
npm run typecheck
npm run lint
npm run format:check
npm run build
npm run dev
```

その後`http://localhost:3000/`を開く。`npm run sync:data`は想定schemaだけを受け付け、hash manifestを生成する。CIはbuild前に`npm run verify:data`を実行する。
